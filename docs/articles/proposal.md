## Final Project Proposal

To the BST260 Teaching Team, Fall 2026,

The overall goal of my project is to build an R package and pkgdown site
around the latest NHANES data. My research question will be built on two
parts:

1.  The first vignette explains how to run the newest Epiconnector
    Docker image, and how to use nhanesA to pull and process its tables
    into a functional dataset. Dr. Carey has also asked that I write up
    some content on the container concept as well.

2.  The second vignette uses that data to analyze the association
    between an exposure and a health outcome, applying the most recent
    NHANES data pulled using the nhanesA R package and my Docker image.
    I have decided to hold off on choosing a particular set of
    exposure/response variables because I will need to get familiar with
    Epiconnector before I can actually explore the data.

For now, I will tentatively propose the following research question:

How does food security relate to diabetes risk?

Once I can pull this data, I will specify the unit of
analysis/population, describe how I’ll handle missingness, and elaborate
on confounders (although I have a hunch that income could be a
confounder here).
